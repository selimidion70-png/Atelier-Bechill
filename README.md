# Atelier-Bechill
# 🧘 BE CHILL — Salon de Massage

> Projet réalisé lors d'un Hackathon à l'EFP Bruxelles en 3 jours, en équipe de 10 personnes.

---

## 📌 Description

**BE CHILL** est une landing page pour un salon de massage fictif.  
Le projet comprend une interface moderne et responsive, ainsi qu'un formulaire de contact fonctionnel développé en PHP.

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- PHP

---

## ✨ Fonctionnalités

- Page d'accueil attractive et responsive
- Présentation des services du salon
- Formulaire de contact avec traitement PHP
- Design adapté à tous les écrans (mobile, tablette, desktop)

---

## 👥 Équipe

Projet réalisé en équipe de **10 personnes** dans le cadre d'un Hackathon organisé par l'**EFP Bruxelles**.

---

## 🚀 Lancer le projet

1. Clone le repository :
   ```bash
   git clone https://github.com/selimidion70-png/be-chill.git
   ```
2. Ouvre le projet dans ton éditeur (VS Code recommandé)
3. Lance un serveur local PHP :
   ```bash
   php -S localhost:8000
   ```
4. Ouvre ton navigateur sur `http://localhost:8000`
